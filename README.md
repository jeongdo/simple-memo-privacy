## Maintenance / retirement policy

- Authoritative **app-bundled** policy text remains in the Simple Memo Android repository.
- Authoritative **public web** policy text and translations are managed in the private [jeongdo-apps](https://github.com/jeongdo/jeongdo-apps) source repository and served publicly through Cloudflare.
- This legacy repository should receive no new features. Keep existing policy text resources and URL paths intact.
- **Do not delete, unpublish, or privatize this repository solely to reduce GitHub repo count.** Such changes can break old policy URLs even if the canonical copy is healthy.
- After completing migration, archiving the GitHub repository is preferable to deletion as long as its GitHub Pages site remains publicly accessible. To update the legacy copy later, unarchive first.
- This site neither runs AdMob nor hosts app-ads.txt; those declarations belong at the root of the corresponding developer website host.
